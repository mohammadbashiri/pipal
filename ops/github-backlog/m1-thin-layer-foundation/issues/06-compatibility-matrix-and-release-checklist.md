# Compatibility Matrix + Release Checklist

## Why
A thin wrapper lives or dies by compatibility confidence.

## Deliverables
- Add matrix: tested `pipal` version vs tested `pi` version(s).
- Add release checklist to verify compatibility and quickstart before tagging.
- Add changelog discipline for breaking vs non-breaking wrapper behavior.

## Acceptance criteria
- Every release can point to tested compatibility versions.
- Contributors have a clear release gate.
