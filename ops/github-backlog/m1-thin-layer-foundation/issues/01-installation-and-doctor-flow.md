# Installation + Doctor Flow

## Why
The project promise is "if pi works, pipal works." Setup must be deterministic and self-diagnosing.

## Deliverables
- Canonical install path in README.
- Canonical verification path (`pipal check-pi-compatibility`).
- Improve doctor output with actionable fixes for common failures.
- Add a short troubleshooting section for installation/runtime mismatch.

## Acceptance criteria
- Fresh environment docs path works end-to-end.
- `check-pi-compatibility` output points to concrete commands to fix detected issues.
- README quickstart has exactly one primary flow.
